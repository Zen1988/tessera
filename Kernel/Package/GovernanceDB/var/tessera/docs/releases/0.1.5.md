# TESSERA-Base 0.1.5

This cumulative candidate simplifies Network simulation access to enablement/exact login grants. Integration onboarding owns the connection, collection namespace, CMDB identity namespace; the Application GO Navis field owns its stable topology name. The customer form no longer requires environment or UUID selection. New traces use the on-demand default or send topology_name directly. UUIDs remain per-operation evidence; original submitted requests are preserved separately.

Agent NavisControl also supports Default traces without an application graph and trusted Application contexts by name or explicit retained version. Pinned legacy callers remain supported. Topology creation/read/by-name/history/compare/refresh, collection progress, ingestion status and session graph routes are registered when a managed Navis connection is saved. Edit/save the existing connection after upgrade to install its new invokers; old connections are not silently rewritten.

Readback ingestion carries a backend-owned run ID and expected submission/item totals. GET-only reconciliation distinguishes pending, failed/raw-only and normalized complete. No graph-readiness or connectivity claim follows from ingestion success. Duplicate callbacks and recommendation refreshes do not replay mutating calls.

The trace graph shows anonymous grey restricted nodes with the Application system name only, explicitly authorized by the owner. Hidden CI name/IP/class/IDs/attributes/links remain undisclosed; detailed path evidence and recommendations remain withheld across restricted scope. Unmanaged/missing segments are distinct and unknown. Inventory evidence is not connectivity proof. Mobile layout and keyboard inspector are included.

Documentation now has architecture, operations, integrations, administration, development and ScriptEngine sections plus an inventory of older references. The README uses a 180px logo and current package authority. Superseded simulation/deployment guidance is marked. The offline authoring pack contains AGENTS instructions, exact packaged interpreter/adapters,11 source examples,631 dated native field definitions, class/catalogue schemas, derived XML/JSON references, hashes and offline validation tools. Derived XML is not a native import format.

Requires the matching newer Navis named-topology/visibility/progress implementation and migrations through 021. See reference/navis/PROVENANCE.json; older published acd2b5d alone is insufficient for topology_name. Navis is now published at2a43005e445c2a33f6b6139cc8e8e6d05140feff. The other chat performed its implementation/publication; its files were not overwritten here. No live upgrade, image build, database cleanup or GitHub publication was performed here.

The optional Application GO Navis Text field and explicit Default/Application trace selector are included, with an idempotent native installer that preserves existing pages/roles and values. Full discovery scheduling and application membership/topology-creation automation remain pending; the full pipeline is not claimed deployed. Legacy environment bindings and stored analyses remain preserved, while new traces do not fall back to them. No Config.pm Secret replacement or generated ZZZ transfer is required.

Exact artifacts/checks are recorded in outputs/base015-validation.json and companion checksums. Native Linux fresh/upgrade/reinstall, real database failures/concurrency, production theme and remote discovery/trace acceptance remain pending.
