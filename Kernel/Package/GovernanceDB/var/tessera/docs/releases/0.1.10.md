# TESSERA-Base 0.1.10 — OTOBO 11.1.1 compatibility

Merges the 37 runtime paths identified in the source host's 38-entry upgrade
report onto official OTOBO 11.1.1. The remaining entry is the TESSERA README.
All 15 additional Custom source files were supplied and hash-verified before
merging. Existing package release artifacts remain unchanged.

Preserves TESSERA portal/workflow/entitlement controls and the installed customer
multitenancy, service catalog, ConfigItem and database-field extension behavior.
Retains stable reference/Lens/Set handling, dynamic-field filtering and native
GenericAgent import/export validation. Database-field cache invalidation now
uses the stable Set-row storage structure and runs only after successful writes.
Avatar initials accept native and TESSERA customer name keys.

The installer checks the reviewed native and Custom source hashes before
governance bootstrap changes. Known legacy package-native bases are permitted
because a separate package repair can restore those files; unknown modifications
require a compatibility merge. The native framework minimum is 11.1.1.
Do not install this package into the beta installation before the core update.

Use the matching native upgrade helper and its --tessera-package option. It
validates the exact prepared report against the packaged compatibility manifest,
backs up before writes, stages merged runtime files before native DB migration,
upgrades TESSERA, repairs other installed packages, then reinstalls TESSERA and
verifies every merged target. Successful apply leaves services stopped.

No new governance fields, schema, membership, ticket routing or grants are
introduced. The separate experimental beta-version comparison bridge is excluded.
Linux migration, restored-backup acceptance and live integration acceptance
must be performed on the source-host clone before production rollout.
