# Base0.1.11 — compatible add-on reconciliation

Merges the official ITSMConfigItemMultitenancy11.1.1 customer list/search,
Elasticsearch and permission changes with TESSERA's portal entitlement,
ticket/FAQ scope and internal-article restrictions. Native agent item-group
checks are retained. Anonymous CI detail remains denied under the authenticated
TESSERA asset contract. No new fields, roles, memberships or routing are added.

Explicitly requires ITSMConfigItemMultitenancy>=11.1.1; upgrade that dependency
before Base0.1.11. Fresh installs need the same compatible dependency.
Installer preflight accepts only reviewed vendor/Base overlap hashes.
Same-version reinstall and upgrades preserve existing governance data.

The native continuation upgrades five installed11.0-only add-ons using pinned
official11.1 releases, then upgrades Base, repairs package deployment, reapplies
Base last and rebuilds configuration/assets. It retains the original startup
snapshot and never repeats the completed OTOBO DB migration or registry recovery.
Old OPMs remain immutable. Live source-host acceptance is still required.
