# Current limits and pending work

- Only documented VERSION 1 constructs are supported. Script grammar is caller-specific.
- The pack is self-contained reading/authoring material, not a packaged live database or portable Perl binary distribution.
- Dated native exports do not include every site customization or all later managed-field changes. Read package/default/installer provenance.
- Interpreter validation is not a complete approved-definition publication gateway.
- Source-level Set support does not create a RiskAggregationEngine or arbitrary automation executor.
- External calls need explicitly supplied authorized providers; native runtime dependencies remain required.
- Control errors do not become Pass; successful partial effects can require idempotent reconciliation.
- Navis unknown/incomplete evidence is not connectivity success. Recommendations are drafts.
- Application Navis label storage and explicit trace selection are implemented; full discovery scheduling and member-selection/topology-creation automation are not implied by API routes or that field.
- Native Linux installation, real DB concurrency, production theme and live remote acceptance must be separately recorded.

Use the manifest's package version/hash to detect drift. Refresh this pack when language, fields, caller contracts or adapters change; never silently use an old pack to invent support in a newer/older deployment.
