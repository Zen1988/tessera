# Portal administration

In Admin Utilities configure icons, HTTPS targets/internal adapters, parameter mapping, audiences, enabled state and order. Show as a Workplace shortcut provides direct CyberArk-style icons outside the full catalogue. A blank card means no authorized enabled shortcut; it does not grant target access.

Network simulation access accepts exact active customer logins, one per line. Email works only if it is the login. Numeric agent IDs, display names and company wildcards are not accepted. Configure connection/namespaces in Integration onboarding. Configure the stable topology label in the Application GO Navis field; choose Default network or Application explicitly in the trace workspace.

Change uses protected ChangeType and ChangeClassification, with Normal and Not-Assessed defaults respectively. Requesters cannot declare them on creation. Manager groups are configurable; IPC has documented reasoned overrides. Approved Major announcements are limited portal-wide projections with the submitted four-phase runbook. Request context shows both fields below Type and Major in dark orange.

Risk assessment resolves catalogue names and writes readable article evidence using existing ZRM fields. Requester Hold/Resume changes execution state without rebuilding Book position or spawning children.
