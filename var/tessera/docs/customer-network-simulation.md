# Customer network simulation

Current guide: [Navis workflow](integrations/navis.md). Base0.1.5 replaces mandatory PROD/environment selection and manually pinned per-environment UUIDs with integration-owned on-demand or exact-name selection.

Grant exact customer logins in Network simulation access. Configure connection and namespaces in Integration onboarding, and the stable graph label in the Application GO Navis field. Choose Default network or an entitled Application explicitly for tracing. Utilities controls Workplace icons. Customers choose authorized endpoints/service; CMDB entitlement and path withholding remain enforced.

Legacy Bindings remain only for saved analyses. They are not used for new traces. Navis migration018, identity/source permissions and native acceptance remain required. Earlier environment-pinned setup is superseded; consult immutable old OPMs for that behavior.
